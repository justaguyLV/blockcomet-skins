# BlockComet Skins

Shared skin registry for **BlockComet Launcher** players using a *local* account.

Every file in `skins/` is named after a player: `skins/<PlayerName>.png`.
BlockComet adds this folder as a skin source (through the CustomSkinLoader mod), so everyone playing with BlockComet sees
that player wearing the skin, in singleplayer and on servers that allow it.

## Add your skin

1. Make a **64x64 PNG** skin (classic or slim; the model is detected automatically).
2. Name it exactly like your in-game name, same capital letters: `Steve.png`.
3. Open a Pull Request adding it to `skins/`, or send it to the owner.

Only players who run BlockComet (with its skin mod) see these skins: other launchers show the default skin.
Do not upload skins you do not have the right to share.

# سكنات BlockComet

سجل سكنات مشترك للاعبي **BlockComet** الذين يلعبون بحساب محلي.
كل ملف في `skins/` باسم اللاعب: `skins/<اسم اللاعب>.png`. يضيف BlockComet هذا المجلد مصدراً للسكنات، فيرى كل لاعب يستخدم BlockComet سكنك على شخصيتك.

## كيف تضيف سكنك

1. جهّز سكن PNG بحجم **64x64**.
2. سمّ الملف بنفس اسمك داخل اللعبة وبنفس الأحرف الكبيرة: `Steve.png`.
3. افتح Pull Request يضيفه إلى `skins/`، أو أرسله لصاحب المستودع.

السكن يظهر فقط للاعبين الذين يشغّلون BlockComet. اللانشرات الأخرى تعرض السكن الافتراضي.
